## 1. Domain Sizing

### External Aerodynamics (Farfield)
| Dimension | Minimum | Recommended | Notes |
|-----------|---------|-------------|-------|
| Upstream   | 10c     | 20c         | c = chord length |
| Downstream | 20c     | 40c         | Must capture full wake |
| Top/Bottom | 15c     | 25c         | Prevents blockage |
| Spanwise   | 1c (2D) | Full span   | Use symmetry for half-model |

### Internal Flow (Duct/Nozzle)
- Inlet: Extend **10 diameters** upstream of region of interest
- Outlet: Extend **20 diameters** downstream

## 2. blockMesh C-Grid for 2D Airfoil

The C-grid topology is standard for airfoils: wrap C-shape around leading edge, extend wake behind trailing edge.

### `constant/polyMesh/blockMeshDict` (NACA 0012 example, unit chord)

```cpp
/*--------------------------------*- C++ -*----------------------------------*\
  NACA 0012 C-Grid — 2D Airfoil
  Chord = 1.0 m, Re ≈ 6e6, Farfield ≈ 20c
\*---------------------------------------------------------------------------*/

FoamFile { version 2.0; format ascii; class dictionary; object blockMeshDict; }

scale 1.0;

// Key parameters
// C-grid wrapped around airfoil
// 3 blocks: upper, lower, wake

vertices
(
    // Farfield C-arc points (radius = 20c) ...
    // [Full vertex list depends on airfoil shape — generate with PyFoam or Pointwise]
    // Example structure only:
    ( -20  0  0)    // 0: upstream farfield
    (  20  0  0)    // 1: downstream farfield top
    (  20  0  1)    // 2: downstream farfield top (span=1)
    ( -20  0  1)    // 3: upstream farfield (span)
    // ... airfoil surface points from NACA generation script
);
```

### Recommended Grid Sizes (2D RANS)
| Region | Cells |
|--------|-------|
| Airfoil surface (chord-wise) | 200–400 |
| Normal to wall | 80–120 |
| Wake region | 100–150 |
| Total 2D cells | 40,000–150,000 |

### First Cell Height for y+≈1 (Low-Re)
```
y1 = (y+ × ν) / u_τ
u_τ = U_inf × sqrt(Cf/2)
Cf ≈ 0.026 / Re^(1/7)   (turbulent flat plate, initial estimate)

Example: U=50 m/s, c=1m, ν=1.5e-5 m²/s → Re=3.3e6
Cf ≈ 0.003, u_τ ≈ 1.94 m/s
y1 for y+=1: y1 = 1 × 1.5e-5 / 1.94 ≈ 7.7e-6 m
```

## 3. snappyHexMesh for 3D Wings

### Directory Structure
```
case/
├── system/
│   ├── blockMeshDict       (background Cartesian mesh)
│   ├── snappyHexMeshDict   (refinement + layers)
│   └── surfaceFeatureExtractDict
├── constant/
│   ├── triSurface/
│   │   ├── wing.stl         (watertight surface)
│   │   └── wing.eMesh       (feature edges, generated by surfaceFeatureExtract)
│   └── polyMesh/
└── 0/
```

### Step 1: Background Mesh (`blockMeshDict`)
```cpp
FoamFile { version 2.0; format ascii; class dictionary; object blockMeshDict; }
scale 1.0;

vertices
(
    (-20 -15 -15)   // xMin yMin zMin
    ( 40 -15 -15)   // xMax yMin zMin  (longer downstream)
    ( 40  15 -15)
    (-20  15 -15)
    (-20 -15  15)
    ( 40 -15  15)
    ( 40  15  15)
    (-20  15  15)
);
blocks ( hex (0 1 2 3 4 5 6 7) (60 30 30) simpleGrading (1 1 1) );
boundary
(
    inlet  { type patch; faces ((0 4 7 3)); }
    outlet { type patch; faces ((1 2 6 5)); }
    sides  { type patch; faces ((0 1 5 4)(3 7 6 2)(0 3 2 1)(4 5 6 7)); }
);
```

### Step 2: Feature Edge Extraction
```bash
surfaceFeatureExtract
```
```cpp
// system/surfaceFeatureExtractDict
FoamFile { version 2.0; format ascii; class dictionary; object surfaceFeatureExtractDict; }
wing.stl
{
    extractionMethod extractFromSurface;
    extractFromSurfaceCoeffs { includedAngle 150; }  // degrees — catches sharp edges
    writeObj yes;
}
```

### Step 3: snappyHexMeshDict
```cpp
FoamFile { version 2.0; format ascii; class dictionary; object snappyHexMeshDict; }

castellatedMesh true;
snap            true;
addLayers       true;

geometry
{
    wing
    {
        type triSurfaceMesh;
        file "wing.stl";
    }
    // Optional: refinement boxes
    wakeBox
    {
        type searchableBox;
        min ( 0.0 -2.0 -2.0);
        max (10.0  2.0  2.0);
    }
    leBox  // Leading edge refinement
    {
        type searchableBox;
        min (-0.1 -1.5 -1.5);
        max ( 0.2  1.5  1.5);
    }
}

castellatedMeshControls
{
    maxLocalCells       2000000;
    maxGlobalCells      20000000;
    minRefinementCells  10;
    nCellsBetweenLevels 3;         // cells between refinement levels (2-4)

    features
    (
        { file "wing.eMesh"; level 5; }  // Sharper feature edges get higher level
    );

    refinementSurfaces
    {
        wing
        {
            level (4 6);     // (min max) refinement levels on surface
            patchInfo { type wall; }
        }
    }

    refinementRegions
    {
        wakeBox { mode inside; levels ((1 2)); }
        leBox   { mode inside; levels ((1 4)); }
    }

    locationInMesh (0 0 0.1);   // Point INSIDE fluid domain (not in wing)
    allowFreeStandingZoneFaces true;
}

snapControls
{
    nSmoothPatch        3;
    tolerance           2.0;
    nSolveIter          30;
    nRelaxIter          5;
    nFeatureSnapIter    10;
    implicitFeatureSnap false;
    explicitFeatureSnap true;
    multiRegionFeatureSnap false;
}

addLayersControls
{
    relativeSizes       true;
    layers
    {
        wing { nSurfaceLayers 15; }  // 15 inflation layers on wing
    }
    expansionRatio      1.25;
    finalLayerThickness 0.3;    // relative to cell size
    minThickness        0.001;
    nGrow               0;
    featureAngle        60;
    nRelaxIter          5;
    nSmoothSurfaceNormals 1;
    nSmoothNormals      3;
    nSmoothThickness    10;
    maxFaceThicknessRatio 0.5;
    maxThicknessToMedialRatio 0.3;
    minMedianAxisAngle  90;
    nBufferCellsNoExtrude 0;
    nLayerIter          50;
}

meshQualityControls
{
    maxNonOrtho         65;
    maxBoundarySkewness 20;
    maxInternalSkewness 4;
    maxConcave          80;
    minFlatness         0.5;
    minVol              1e-13;
    minTetQuality       1e-30;
    minArea             -1;
    minTwist            0.02;
    minDeterminant      0.001;
    minFaceWeight       0.02;
    minVolRatio         0.01;
    minTriangleTwist    -1;
    nSmoothScale        4;
    errorReduction      0.75;
}
```

### Run Sequence
```bash
blockMesh
surfaceFeatureExtract
snappyHexMesh -overwrite
checkMesh -latestTime
```

## 4. Prism Layer Design

### Layer Count by Reynolds Number
| Re | Min Layers | Recommended | y+ Target |
|----|-----------|-------------|-----------|
| < 1e5 | 10 | 15 | ≤ 1 |
| 1e5–1e6 | 12 | 20 | ≤ 1 |
| 1e6–1e7 | 15 | 25 | ≤ 1 (or 30-100 w/ wall func.) |
| > 1e7 | 15 | 30 | 30–300 (wall functions) |

### Growth Ratio & Total Layer Thickness
```
Total thickness = y1 × (r^n - 1) / (r - 1)
where: y1 = first cell height, r = growth ratio (1.2-1.3), n = number of layers

Example: y1=7.7e-6, r=1.25, n=20 → total ≈ 1.43e-3 m (0.14% chord)
```

## 5. Mesh Quality Criteria

### checkMesh Thresholds (Aerospace CFD)
| Metric | Acceptable | Ideal | Critical Limit |
|--------|-----------|-------|----------------|
| Max non-orthogonality | < 70° | < 50° | < 85° |
| Max skewness | < 4 | < 2 | < 8 |
| Max aspect ratio | < 1000 | < 500 | context-dependent |
| Min determinant | > 0.001 | > 0.01 | > 0 |
| Min face weight | > 0.02 | > 0.05 | > 0 |

### Interpreting checkMesh Output
```
Mesh OK — if all checks PASS, proceed
High non-orthogonality — use corrected snGradSchemes, add nNonOrthogonalCorrectors 2
High skewness — check STL quality, reduce snap tolerance in snappyHexMesh
Failed cells — investigate with paraFoam, check STL for self-intersections
```

## 6. cfMesh Alternative

cfMesh (cartesianMesh) is sometimes preferred for complex fuselage geometries:
```bash
cartesianMesh   # after setting meshDict
```
```cpp
// system/meshDict
surfaceFile "geometry.fms";
maxCellSize 0.5;
boundaryCellSize 0.05;
boundaryLayers
{
    nLayers 15;
    thicknessRatio 1.25;
    maxFirstLayerThickness 0.001;
}
```

## 7. Common Meshing Errors

| Error | Cause | Fix |
|-------|-------|-----|
| `locationInMesh is not inside` | Point inside solid or outside domain | Move locationInMesh point; check STL |
| Missing prism layers | STL self-intersections near walls | Fix STL with surfaceCheck; reduce featureAngle |
| `Failed to extrude` | Highly curved geometry | Reduce nSurfaceLayers; lower maxFaceThicknessRatio |
| High non-ortho at wing tip | Sharp feature/tip geometry | Use `explicitFeatureSnap`, refine tip region |
| Asymmetric mesh | blockMesh grading off | Check simpleGrading values |
| `No cells retained` | Wrong locationInMesh | Verify point is in fluid domain |
